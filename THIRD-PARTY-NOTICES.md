## ArcWelder (optional external tool — not bundled)

The optional G2/G3 arc-fitting post-process can invoke
[ArcWelderLib](https://github.com/FormerLurker/ArcWelderLib)'s
`ArcWelderConsole.exe` (AGPL-3.0-or-later) as a separate, user-supplied
executable.
ArcWelder is **not** included in this repository or in the distributed
packages; no ArcWelder source code was used. Users who want that feature
download ArcWelder themselves under its own license. The built-in arc-fitting
fallback (`Lugworm.Core/Arcs/ArcFit.cs`) is an independent
implementation.

## SkiaSharp and OpenTK — Duet Console rendering (MIT)

The Duet Console window is drawn with SkiaSharp. The following packages
are redistributed in the plugin package, all under the MIT License:

- `SkiaSharp` 2.88.6 — Microsoft (originally Xamarin). MIT.
- `SkiaSharp.Views.Desktop.Common` 2.88.6 — Microsoft. MIT.
- `SkiaSharp.Views.WindowsForms` 2.88.6 — Microsoft. MIT.
- `SkiaSharp.NativeAssets.Win32` 2.88.6 — Microsoft. MIT. Supplies the native
  `libSkiaSharp.dll`, which wraps Google's Skia (BSD-3-Clause).
- `OpenTK` 3.1.0 — the Open Toolkit contributors. MIT. Pulled in transitively by
  the WinForms views; used only by the optional OpenGL surface.
- `OpenTK.GLControl` 3.1.0 — the Open Toolkit contributors. MIT.

The version is pinned to exactly 2.88.6 on purpose. 
Only the Windows native is redistributed.

## BrickLayers — prior art, idea only (GPL-3.0, NOT vendored)

The interlocking-wall idea implemented in
`Lugworm.Core/Slicing/Bricklayer.cs`, and the wave-modulated infill and
per-loop wall wave in `Lugworm.Core/Slicing/NonPlanarInfill.cs`, were
inspired by Roman Tenger's and GeekDetour's G-code post-processing scripts,
including the behaviour:

- [Bricklayers](https://github.com/TengerTechnologies/Bricklayers) — Roman
  Tenger (GPL-3.0)
- [BrickLayers](https://github.com/GeekDetour/BrickLayers) — GeekDetour
  (GPL-3.0)

**No code, comment, string
or data file from either project has been copied, vendored, translated or
ported line by line.** Reimplemented from scratch.
