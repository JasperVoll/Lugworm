# About

IAMLab Slicer is developed at the Institute of Digital and Autonomous
Construction (IDAC), Hamburg University of Technology, for clay and
cementitious materials in a laboratory setting.

## Contact

Write to [jasper.vollmert@tuhh.de](mailto:jasper.vollmert@tuhh.de) for access
before the first release, to report a machine that does not work, or to
collaborate on making a machine compatible.

Bugs and feature requests belong in the
[issue tracker](https://github.com/JasperVoll/iamlab-slicer-documentation/issues).

[IAMLab Version]({{ '/docs/components/iamlab-version/' | relative_url }}), the
`info` output of the component that failed, and a minimal definition with
