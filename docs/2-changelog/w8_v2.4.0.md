## The component

**IAMLab Graph Mapper** (`1 Slice`, GUID `a1a2c3d4-0027-4bbb-…0027` - the scheme's next
free slot). Same job as Grasshopper's Graph Mapper: remap a number stream through an
on-canvas curve. Graph families: Linear, Bézier (cubic; control-x clamped so x(u) is
monotone - the CSS cubic-bezier guarantee - and the curve can never fold), Power
(Square Root = exponent 0.5), Sine, Parabola, Gaussian, Sigmoid, Perlin (deterministic
seeded 1D gradient noise). Sine Summation is deliberately folded into Sine's frequency
handle rather than cloned.

## The improved mechanics (the point of the request)

- **Real undo**: every grip drag, type switch, reset and reseed records a component
  undo snapshot before mutating - ctrl+Z restores the exact previous curve. (The same
  hook was added to the 2.3.0 goal-curve strip, closing its stated no-undo gap.)
- **Grid snapping**: Ctrl = 0.05, Shift = 0.01 while dragging.
- **Live numeric readout**: exact grip t/y during a drag; the curve's formula
  (`equation` output and strip footer) otherwise. The stock mapper shows neither.
- **Hover feedback**: grips highlight with their name before you commit to a drag.
- **The wired data is visible**: input values tick the t axis, mapped outputs tick
  the y axis - the stock mapper never shows what it is mapping.
- **Per-family memory**: switching Bézier → Sine → Bézier restores the Bézier
  parameters; ↺ resets only the current family. The stock mapper forgets.
- **Wireable domains**: `inMin/inMax/outMin/outMax/clip` as an optional input group
  instead of a modal double-click dialog.
- Graph type on an on-canvas dropdown capsule; curve + memory persist in the `.gh`.

## Where the code lives

Curve math is Core and Rhino-free (`Core/Analysis/GraphMap.cs`; evaluate, domain
remap, serialize) - `GraphMapTests` pins closed-form values, Bézier identity and
monotonicity, Perlin determinism, domain remap and round-trips (12 tests). The strip
(`Ui/GraphMapEditor.cs`) implements the `ICanvasStrip` interface extracted from the
2.3.0 goal editor - `IamAttributes` now hosts any such strip and routes hover.
Icon is runtime-drawn for now; `icons-src/IAMLab/IamGraphMapper.svg` is committed for
the `make_icons.ps1` pipeline (swap to the PNG when generated - TESTING row).
