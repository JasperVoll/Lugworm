## 1. Custom graphs - points you own

Two new point-based families with a variable-length (t, y) vector:

- **Polyline** - linear interpolation through the points.
- **Spline** - smooth interpolation via Fritsch–Carlson monotone cubic Hermite
  (SIAM J. Numer. Anal. 17(2), 1980; written from the definition): the curve passes
  through every point and never overshoots between them, so a monotone stretch of
  points is a monotone stretch of curve - the right behaviour for a mapping curve,
  where Catmull-Rom-style overshoot would invent values nobody placed.

Mechanics: **double-click empty plot adds a point at the cursor; double-click a grip
removes it** (floor of two points); every point drags freely, with t clamped between
its neighbours so the list stays sorted. Outside the first/last point the curve holds
that height. Both gestures record an undo snapshot first. The type dropdown gains
**Convert → Polyline / Spline (9 pts)**, sampling the current analytic curve into an
editable one - the bridge from every family to free editing. Serialization carries
the variable-length vector whole (`GraphMapTests` pins round-trips and structural
fallbacks); per-family memory accepts any valid point list, not just the default
length.

## 2. More graph types

- **Conic** - superellipse quadrant `y = 1 − (1 − t^a)^(1/a)` (a = 2 is the circle),
  one eccentricity grip.
- **Exponential** - `y = (e^(k×t) − 1)/(e^k − 1)`, k ∈ [−10, 10]; the k → 0 limit is
  the identity and negative k gives the logarithmic shape, so one family covers both
  stock Exponential and Log reading.
- **Steps** - n equal treads (n ∈ [2, 20]), grip on the first riser; made for
  quantizing a gradient into discrete layer bands.

Single-grip families (Power, Conic, Exponential) drive their parameter by
bisection-inverting the curve value at the grip - the grip lands exactly where it
was dropped.

## 3. Design

- The strip renders on a **`GH_Capsule` face** - the same rounded, shadowed,
  skin-aware surface as every native Grasshopper widget - drawn by `IamAttributes`
  for every `ICanvasStrip` (the Desirability goal strip inherits the look).
- **Width halved**: 190 px (was 372), roughly the stock Graph Mapper's footprint,
  and the strip centres under the component; a strip as wide as a graph card still
  aligns with the card (Desirability column unchanged).
- Plot area gets a quiet theme-background fill inside the capsule so the curve
  surface reads as its own panel on light and dark canvases.
- Title shows the family and, for custom curves, the live point count; the footer
  advertises the double-click gesture instead of a formula no one can edit.

## Compatibility

2.4.0-saved Graph Mappers load unchanged (fixed-length vectors deserialize exactly
as before; the new adoption rule only engages for the new custom kinds). No GUID
changes, no socket changes, `THIRD-PARTY-NOTICES.md` byte-identical, no new packages.
