# 0.1.0-beta — Lugworm rename and first public baseline (worked on as 5.0.0 while private; unreleased)

- Rename (2026-09-22): IAMLab Slicer is Lugworm. Projects, folders, namespaces, assembly
  names, the Grasshopper tab and category, the Yak package (`lugworm`) and the docs follow;
  component names drop the prefix. Settings files save as `*.lwset.json` and the old
  `*.iamset.json` still load; the job-log folder moves once to `%LOCALAPPDATA%\Lugworm`.
  No GUID, nickname, socket or serialised key changed. Major bump: the old package has to be
  uninstalled before the new one installs.

- Pre-release polish (2026-09-23, plan `F_5.0.0_pre-release-polish`):
  - **Console progress `42%  layer 12/40`.** `PrintConsoleState.ProgressText` is the one
    formatter for the header, Dashboard and Job page. The total is `JobSnapshot.LayerTotal()`
    (the job's `; layer N/M` markers, via `GcodeLayerMarkers.TotalLayers`, scanned once per
    snapshot), else the firmware's `job.file.numLayers` (`JobState.FileLayerCount`), and it
    is assigned on every poll so one job's total never sticks to the next. Tests:
    `JobProgressTextTests`.
  - **Live View trail retention.** Investigation of the 2026-09-23 print (four pauses): the
    recording was complete and sound (median 0.27 mm, p95 0.89 mm from the G-code; the 1.3 %
    over 5 mm are the known one-poll firmware artifacts, evenly spread). The display lost the
    start of the print to the 5,000-point budget, not to the pauses. `Core/Duet/TrailRetention`
    now simplifies older stretches one ladder step at a time (0.2, 0.3, 0.5, 1, 3 mm, running
    bound 0.2 to 5 mm), keeps the live run's newest 600 points, and discards only past
    4 x the budget. The trail no longer draws Pausing/Paused/Resuming. Tests:
    `TrailRetentionTests` (25,000 points in one run keep the first; every observation stays
    within its stated bound).
  - **Zigzag boundary connector.** `Infill.ZigzagSpans` joins row ends along the shared
    boundary ring when the straight join would leave the region, as `WaveSpans` did. Both now
    cap the detour at two row pitches (`MaxConnectorDetourPitches`): the uncapped rule laid
    three beads over a hole's edge. `SlicePipelineTests` tube golden re-recorded (99 -> 81
    paths). Tests: `ZigzagConnectorToleranceTests`.
  - **Pump-agnostic pump mode.** The MAI branding and `PumpModel.RatedFlowMin/MaxLpm` are gone;
    the calibration table's range is the only range. Placeholder CSV and XLSX renamed
    `pump_calibration_placeholder.*`; the workbook was edited in place (three parts rewritten,
    every other part byte-identical, the Check column no longer tests a rated range).
  - **Legend registry of 35 engineering palettes with frozen numbers.** 112 palettes removed
    (all ggsci, 18 matplotlib, 8 R) together with `tools/color_schemes/ggsci.json`; kept
    stops byte-identical; `pinks`/`ambers`/`gray(s)` re-pointed to Purples/Oranges/Greys.
    `ColorSchemes.Normalize`/`NumberOf`, a grouped value list, and the generated
    `docs/reference/legend-palette-table.md`. Tests: `LegendSpecTests`,
    `test_color_schemes_sync.py` (pins every number).

- Duet Console (2026-09-23): the console component is **Duet Console** again (Machine Console
  from 4.0.0 to 4.4.0), because the Moonraker transport left in 4.1.0 and only Duet boards are
  controlled directly. `MachineConsoleForm` is `DuetConsoleForm` (`git mv`); the window title,
  the rail label, the socket descriptions that name it and the docs follow. GUID, nickname,
  sockets, wires and the `duetprintconsole` settings key are untouched. `MachineSession`,
  `MachineComponentBase` and Machine Files keep their names.
