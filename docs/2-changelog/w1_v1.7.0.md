## Changes

Hardening release driven by an in-depth internal audit of the core pipeline and machine-control path. Also adopts the previously uncommitted Duet control work (7 Print tab).

### Machine-path safety (fail closed)

- G-code validation parser rebuilt: word-level lexer (compact `G1X10`, `G01`, N-numbers), strict-reject of unmodeled executable commands, separate logical/offset/physical coordinate tracking — `G92` now changes the workspace offset, never the physical position used by robot checks
- Calibrated post-`homeall.g` home pose contract (`robot.xml` `<HomePose>`; when marked uncalibrated, job validation blocks until measured. The bundled profile carries the pose measured on the lab machine 2026-07-17: X200 Y-500 Z400); per-axis `G28 X/Y` rejected (SCARA joint homing moves both Cartesian axes); homing must precede first motion; intermediate homes re-anchor segment validation
- Segment-interior safety checks (dead zone, joints, mast) wired into every linear move and arc sample; mast-clearance and self-collision findings now block jog and calibration motion unconditionally
- Duet sends: gate evaluation moved inside the serialized command transaction (fresh snapshot under the command lock — TOCTOU closed); 503 retries only idempotent reads; `M999` gated behind Halted/Off or an armed maintenance override; jog while paused refused by default (maintenance override available)
- Upload verification proves remote content identity before every `M32`/`M37` (hash where supported; size+CRC echo on legacy RRF 3.1.1); "print started" only after a confirmed transition to Processing/Simulating
- Jerk dialect fix: RRF `M566` (mm/min) vs Marlin `M205` (mm/s) — previously the same number was emitted to both (×60 physical error on one dialect)
- Terminal component: diagnostic allowlist + expert unlock with 5 s confirm for motion/config/job commands

### Correctness

- Toolpath topology: zigzag/spiral/Fermat infill spans no longer joined by extruding connectors; open mesh sections partitioned out of polygon nesting/offset; Clipper rings explicitly closed; cyclic RDP for closed rings; spiralization requires a closed ring
- G-code builder: skirt routed through the approach/prime state machine; floor pause updates planner state; arc-aware coast; start point = first material point; time estimate uses emitted feeds; validated-config chokepoint rejects non-finite inputs
- Restart: `G92` XYZ offsets honored in both passes, typed modal snapshot replay, byte-accurate percent mode (raw `gcodePath` or uploader-serialization reconstruction), nearest-point-on-geometry cuts with proportional-E splits
- Seam mode 5 tracks per-(object, contour) lineage; stagger mode derives layer index from tree paths
- Session lifecycle: document-refcounted Duet sessions (last close stops the poll loop), async disposal, single 401 re-auth, host canonicalization, JSON depth/size caps, homing-macro probing, fresh-state file operations
- ScaraFit: stalled ≠ converged, physical parameter bounds, quality-gated `robot.xml`/M669 outputs
- Full-circle G2/G3 (coincident endpoints) = ±2π sweep everywhere (centralized in `Move.SweepAngle()`)

### Performance (heavy use)

- Z-bucketed slicing (was O(layers × faces)), spatial nesting parent search, incremental arc fitting, SegmentGrid reuse with bounded queries, coalesced canvas redraws (was per solve iteration), preview budgets + scrub caching, lazy G-code text, typed Duet notifications + job identity caching (was full-file rehash per poll), streaming CRC transfers
- New release-gating scale tests: 1,000 layers, 100k-segment contours, deeply nested rings, arc worst cases, allocation budgets

### UX polish
