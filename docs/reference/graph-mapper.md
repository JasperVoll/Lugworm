# Graph Mapper component

Moved verbatim out of `../ARCHI.md` section 10 during the 4.4.0 documentation compaction.
ARCHI keeps what the component is and where its maths lives; the family list and the
editor mechanics live here.

**Graph Mapper** (`1 Slice`, since 2.4.0, extended 2.5.0): the stock Graph Mapper's job — remap a number stream through an on-canvas curve (grading layer heights, feeds, parameters along a path) — rebuilt on the shared `ICanvasStrip` editor with the mechanics the stock one lacks: hover-highlighted grips, live numeric readout, Ctrl/Shift grid snapping, wired data as axis ticks, real ctrl+Z undo (`RecordUndoEvent` snapshot before every mutation), per-family parameter memory across type switches, and wireable input/output domains instead of a modal dialog. Families (Core, `Core/Analysis/GraphMap.cs`, unit-tested in `GraphMapTests`): Linear, Bézier (monotone-x by the CSS cubic-bezier argument), Power, Sine, Parabola, Gaussian, Sigmoid, deterministic Perlin, Conic (superellipse), Exponential (k→0 limit = identity, k<0 log-like), Steps, and two fully custom point-based families — **Polyline** and **Spline** (Fritsch–Carlson monotone cubic, 1980: shape-preserving, no overshoot) — with variable-length (t, y) vectors: double-click adds a point, double-click a grip removes one (floor of 2), drags stay sorted via `MovePoint`, and any analytic family converts into them by sampling (`ToCustom`, dropdown entries). The strip renders on a `GH_Capsule` face (Grasshopper-native look, drawn by `IamAttributes` for every `ICanvasStrip`) at ~190 px — roughly the stock mapper's footprint — and centres under the component; single-grip families (Power, Conic, Exponential) drive their parameter by bisection-inverting the curve at the grip. The plugin layer only turns gestures into parameter changes.
