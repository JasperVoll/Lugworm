# Test inventory: suites, fixtures and the compatibility gate

Moved verbatim out of `../ARCHI.md` section 21 during the 4.4.0 documentation
compaction. ARCHI keeps the strategy and every gate; the per-suite inventory, the
fixture provenance and the probe list live here.

## Automated suites

- **Automated:** xUnit on Core only — `dotnet test Lugworm.Core.Tests/Lugworm.Core.Tests.csproj`. The suite itself is the gate - run it rather than trusting a count quoted here (947 passing as of v2.6.0, 1208 on 2026-09-07, 1348 at 4.0.0; such numbers go stale between releases). The 2026-09-07 readiness work added `LivePoseTimelineTests`, `LivePathDeviationTests`, `DeviationColorScaleTests`, `LogRetentionTests` (fake file system + clock), `ParetoSelectionTests`, `DoeReportingTests`, `DoeExportSnapshotTests` and the console state's Validate/dry-run/next-action cases. 4.0.0 added `KlipperCommandsTests`, `LegendSpecTests`, `ComponentSettingsTests` and the Spline-handle cases in `GraphMapTests`; its Moonraker, thermal and filament suites went with the features they covered in 4.1.0, all but one. That one is load-bearing and was kept: the byte-for-byte pin of the ram output moved out of `FilamentGcodeTests` into `GcodeBuilderTests.RamOutput_MatchesV4Baseline` **before** anything was deleted, and was then verified to pass against a worktree at the pre-removal commit - which is what makes "the removals changed no paste G-code" a measurement rather than a hope. 4.1.0 adds `BricklayerTests`, `NonPlanarInfillTests`, `WaveInfillTests` and `LayerBuilderTests`. Since 2.6.0 it includes a German ambient-culture fixture (`CultureInvarianceTests`: Marlin, RRF, restart and Duet JSON identical under de-DE), file-level CSV format detection, Duet transport caps and identity trust, SemVer/update-check, and the sample/point normalization regressions. Organization mirrors Core namespaces; includes regression (`BugfixRegressionTests`), robustness, and perf smoke tests (`Category=perf` trait, not excluded by default).

## Fixtures

- **Fixtures:** `foundation.json` (Python-parity provenance; regeneration script currently broken — legacy Python tree deleted), the real `robot.xml` linked from plugin resources, and since 2026-09-09 two telemetry replay captures: `fixtures/dome-20260909/` (the operator-confirmed false-position run - `print.csv`, `events.log`, `manifest.json` and `intended-path-layers.gcode`, a trimmed header-plus-spike-layers extract of the 2.6 MB job written by `docs/dev/analysis/trim_dome_gcode.py` with the source hash in its header) and `fixtures/log-20260902/print.csv` (the homing/footer discontinuity run). `RecoveryTests` pins the E-Stop lockout of the same day against fake transports, and `fixtures/dome-20260909/polls-20260909-1317.csv` (every poll of the 13:17 run with the firmware's `machinePosition` and `userPosition` per axis, projected losslessly from `diagnostics.jsonl`) replays the single-axis glitch through `AxisGlitchFilter`.

## Machine transports

- **Machine transports:** a scripted `HttpMessageHandler` fake RRF board (`DuetClientTests.cs`). The 4.0.0 Moonraker fake went with its transport in 4.1.0; the seam it proved out (`IMachineClient`) stayed.

## Compatibility gate and the offline probes

- **Compatibility gate:** `tools/verify-component-contracts.py` and `tools/verify-rhino-contracts.ps1` enumerate actual plugin contracts and round-trip wired GH documents with solving disabled. The launcher requires a fresh run-ID assertion report and fails on timeout. `tests/grasshopper/component-contracts-v3.json` pins the unchanged 3.0 source before readiness work; all 29 components and 375 default/589 expanded wires passed in Rhino 8.34 across the three plugin payloads. Two offline solving probes ride on the same launcher: `-Probe pareto-selection` (selection, reorder, archive round-trip without upstream data, refused foreign key, copy isolation) and `-Probe interlayer-time`. Neither has been executed on a host yet - they are owed to the manual round. The default `contracts` probe was executed for the first time on 2026-09-09 (see below). This is not historical-file, solve, viewport or hardware acceptance. Pure comparator, source-allowlist, console-parity, DoE-export and public-link tests run with `python -m unittest discover -s tests/tooling` (30 tests at 4.1.0; two 4.0.0 console-parity guards that required the Thermals page were replaced by guards that the surface stays removed).
