# The component contract gate: invocation and the 4.1.0 host run

Moved verbatim out of `../ARCHI.md` section 21 during the 4.4.0 documentation
compaction. ARCHI keeps the allowance table and the rule that the baseline is still
v3; the command-line syntax and the host-run record live here.

**The 4.0.0/4.1.0/4.2.0 contract invocation.** The baseline is still the untouched `component-contracts-v3.json` - **no v4 baseline was ever captured**, because 4.0.0's host run was never performed, so 4.1.0 and 4.2.0 declare their breaks against v3 alongside 4.0.0's rather than against a file that does not exist. All three releases declare every deliberate break on the command line rather than recapturing, so the comparison stays a comparison. `-AllowedAdditions` and `-AllowedRemovals` take **comma**-separated GUIDs; `-AllowedChanges` takes **semicolon**-separated `guid:keys` entries where `keys` is either the literal `all` or a comma-separated list of record keys (`tools/verify-component-contracts.py` splits an entry on the first `:` — note it is a colon, not `=`). The record keys are `guid`, `class`, `name`, `nickname`, `category`, `subcategory`, `exposure`, `active_groups`, `inputs`, `outputs`, `all_input_specs`, `groups`; both the `default` and the `expanded` document are compared with the same allowances, which is why a component whose change only shows up in the expanded record still needs it. What changed against v3:

**The 4.1.0 comparison was run on a host on 2026-09-09 and passed** on Rhino 8.34 for all three payloads (31 components, 374 default / 586 expanded wires), with every declared allowance and nothing else differing - the first time this probe has ever executed. It found the probe itself broken: the reflection call to `SyncInputs` passed no arguments to a method with two optional parameters, a defect older than the v3 baseline that had simply never been exercised. **A post-4.0.0 baseline is still owed**, and 4.1.0 does not discharge it. Capture it only after the manual round passes, with `-Capture -Baseline tests/grasshopper/component-contracts-v4.1.json`; `-Capture` refuses to overwrite an existing baseline and refuses any `-Probe` other than `contracts`, so the file cannot be written to paper over a comparison failure.
