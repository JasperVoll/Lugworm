Give src without an extension: the include looks in assets/images/ for .mp4, .webm, .gif and .png in that order and renders the first file that exists (a video element for mp4/webm, an image otherwise). A src that carries an extension is used as-is. Until a file exists, the page renders a pending note naming the expected path.
