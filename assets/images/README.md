# Screenshots

Images for the documentation site. Drop a PNG in at the path listed below and
the page renders it automatically with the caption shown here; no page edit is
needed. Until the file exists, the page shows a pending note naming it.

Capture at 2x (retina) if possible, PNG, trimmed to the relevant area, with the
Grasshopper canvas at 100% zoom. Keep machine passwords, IP addresses and file
paths out of frame.
