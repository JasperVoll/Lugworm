# Public source allowlist.
#
# Paths of this repository that reach the public GitHub repository. tools/release.ps1
# builds the scanned export (dist/source-Lugworm-<version>.zip) from these committed
# paths, tools/publish-source.ps1 replaces exactly these paths in the public checkout
# with that export, and the tooling tests read this file. One path per line, relative
# to the repository root, forward slashes; a directory exports everything committed
# below it. Everything not listed stays private. In the public repository these paths
# are owned by this tree and overwritten on every import; site/, .github/, and the
# public .gitignore are owned by the public repository. Never list .gitignore (it
# names internal folders) or docs/github (a separate repository).
#
# The public repository carries the code and the documentation site only. Nothing
# under docs/ is exported (no architecture notes, references, user guide, changelog
# or dev docs) and neither is UPGRADE.md: the site is the single source of truth for
# users. README.md, CONTRIBUTING.md, INSTALL.md and THIRD-PARTY-NOTICES.md are the
# maintainer's public text: keep them short and identical in both repositories.
#
# A line starting with "!" keeps a path below an exported directory private: it is
# left out of the export, and because the import replaces the whole directory, it is
# removed from the public checkout on the next import. It may name a path that is not
# committed (yet). Icon and logo sources and the scripts that draw them stay private:
# the release carries only the rendered icons the build embeds and package-icon.png.
